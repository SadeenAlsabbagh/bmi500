--------------

dimensions, malformed rows, and non-numeric values.

For large inputs, this performs many repeated runtime type checks.

RECOMMENDATION:
If explicit validation is required, validate the input values once before the
main arithmetic loop or place validation in a small helper function.

Example:

    def _validate_numeric_list(v, name):
        if not isinstance(v, list) or not v:
            raise ValueError(f"{name} must be a non-empty list.")
        if not all(isinstance(x, (int, float)) for x in v):
            raise TypeError(f"{name} elements must be numeric.")
